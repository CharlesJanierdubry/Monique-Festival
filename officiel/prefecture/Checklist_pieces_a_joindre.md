## Checklist des étapes pratiques

### Avant dépôt
- [ ] Vérifier que tous les PDF signés sont bien lisibles
- [ ] Compléter les champs [entre crochets] dans le courrier d'accompagnement (date, adresse siège, coordonnées)
- [ ] Compléter les données d'état civil de Judith et Wadih dans la Notice et le courrier
- [ ] Scanner les pièces d'identité (recto-verso, format PDF)
- [ ] Créer un compte sur **Le Compte Asso** si ce n'est pas déjà fait : https://lecompteasso.associations.gouv.fr/
- [ ] Préparer un **dossier ZIP** de toutes les pièces (sauvegarde)

### Dépôt en ligne (option privilégiée)
- [ ] Connexion **Le Compte Asso** avec les identifiants de la Présidente
- [ ] Rubrique "Mes démarches" → "Modifier les informations de mon association"
- [ ] Sélectionner les modifications : Dénomination / Statuts / Dirigeants / Siège
- [ ] Remplir les champs, uploader les pièces
- [ ] Valider et envoyer
- [ ] Conserver **l'accusé de réception électronique**

### Dépôt papier (option de secours)
- [ ] Imprimer tous les documents
- [ ] Préparer l'enveloppe LRAR
- [ ] Envoyer à **Préfecture du Doubs — Bureau des associations, 8 bis rue Charles Nodier, 25000 Besançon**
- [ ] Conserver l'accusé de réception

### Après réception du récépissé
- [ ] Classer le récépissé dans `officiel/prefecture/recepisse/`
- [ ] Informer **Qonto** (mise à jour dénomination sociale bancaire)
- [ ] Informer **INSEE** (via SIRENE, mise à jour automatique + changement APE 93.29Z → 90.01Z)
- [ ] Envoyer **courriers d'information partenaires** (voir livrable C)
- [ ] Mettre à jour les **documents internes** (papier à en-tête, tampon, signatures email)
- [ ] Mettre à jour le **site web** et les **réseaux sociaux**
- [ ] Informer **Hello Asso** (nouvelle raison sociale)
