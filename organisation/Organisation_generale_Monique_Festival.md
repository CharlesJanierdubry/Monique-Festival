## 2. Astreinte email hebdomadaire

**Boîte mail** : info@monique-festival.fr — partagée entre les 5 chefs de pôle + Luther

**Principe** : chaque semaine, une personne d'astreinte :
1. Accuse réception de chaque message entrant
2. Étiquette le message (#artistique, #com, #admin, #technique, #logistique)
3. Notifie le responsable du pôle sur le canal d'équipe

Le responsable de pôle traite le fond dans la semaine.

**Rotation**

| Semaine | Astreinte |
|---------|-----------|
| 1 | Lewis |
| 2 | Lorraine |
| 3 | Charles |
| 4 | Léopold |
| 5 | Luther |
| *puis recommence* | |

**Pré-requis** :
- 6 personnes avec accès lecture/écriture à info@monique-festival.fr
- Message-type d'accusé de réception prêt
- 5 étiquettes créées dans la boîte
- Canal de notification (WhatsApp / Signal / Discord)
